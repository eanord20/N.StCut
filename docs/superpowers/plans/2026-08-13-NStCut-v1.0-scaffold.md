- [ ] **Step 2: Create solution and projects**

Run in PowerShell from `D:\My_project\N.StCut`:

```powershell
New-Item -ItemType Directory -Force -Path "src"
cd src

dotnet new sln -n NStCut

dotnet new classlib -n NStCut.Core -f net8.0
dotnet new classlib -n NStCut.Dxf -f net8.0
dotnet new classlib -n NStCut.Nesting -f net8.0
dotnet new classlib -n NStCut.Reports -f net8.0
dotnet new wpf -n NStCut.App -f net8.0-windows
dotnet new xunit -n NStCut.Core.Tests -f net8.0
dotnet new xunit -n NStCut.Nesting.Tests -f net8.0

dotnet sln NStCut.sln add NStCut.Core/NStCut.Core.csproj
dotnet sln NStCut.sln add NStCut.Dxf/NStCut.Dxf.csproj
dotnet sln NStCut.sln add NStCut.Nesting/NStCut.Nesting.csproj
dotnet sln NStCut.sln add NStCut.Reports/NStCut.Reports.csproj
dotnet sln NStCut.sln add NStCut.App/NStCut.App.csproj
dotnet sln NStCut.sln add NStCut.Core.Tests/NStCut.Core.Tests.csproj
dotnet sln NStCut.sln add NStCut.Nesting.Tests/NStCut.Nesting.Tests.csproj
```
